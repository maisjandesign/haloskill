# Источники и границы распространения

Снимок: 7 октября 2026 года. Базой служат установленные локальные версии, а не неподтверждённые «последние версии из интернета». Повторная загрузка той же версии не требовалась. Исходные хеши и соответствия имён: [manifest](../sources/manifest.json).

Нельзя утверждать, что весь набор общедоступный или имеет единую открытую лицензию. У локальных методик лицензия не установлена; в частности, Halo-презентации содержат персональные настройки и брендовые материалы. Их сохранение в этом частном репозитории не является присвоением авторства или лицензией на публичное распространение. Не публикуйте весь пакет как open source без проверки прав.

Figma-методики получены из установленного пакета 2.2.120, связанного с https://github.com/figma/mcp-server-guide. Для них также не заявляется лицензия, не подтверждённая локальными материалами.

Sites помечен upstream как Proprietary. В репозитории находятся только написанные для студии адаптеры: исходный plugin и runtime не копируются. Imagegen и Presentations также подключаются как зависимости; их провайдерские реализации здесь не распространяются.

Два Workshop skill предоставлены пользователем отдельно. Изменены только имена, UI-названия, команды вызова и ссылка между skills. References сохранены побайтово. Старые workshop-facilitation и design-sprint-plan не импортированы.

Снимок исходной методики хранится в references/source-skill.md каждого адаптированного skill, с поправкой относительных ссылок из-за перемещения и названий включённых в семейство skills. Невключённые Figma prerequisites отмечены как внешние зависимости. Это техническая основа; актуальные пользовательские инструкции и входной адаптер имеют приоритет. Установка оригинальных зависимостей выполняется отдельно через их поддерживаемый механизм.
