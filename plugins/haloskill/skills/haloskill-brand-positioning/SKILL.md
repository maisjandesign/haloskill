# HaloSkill — Brand Positioning

Use Brand-building's positioning method: identify the priority audience and context, category/frame of reference, current alternatives, meaningful differentiation, benefit and reasons to believe. Start from actual research and existing brand decisions. Separate evidence from aspirations.

Draft a small number of defensible positions: “For [audience/job], [brand] is [category] that [benefit], because [proof].” Compare relevance, credibility, distinction and delivery implications. Test language against customer vocabulary and available evidence. Record tradeoffs and missing proof; the client/brand owner chooses. Update the shared context and hand messaging/voice to Copywriting. Do not reopen approved positioning during routine website production.

## Working contract

Use the existing project brief, decisions, approved assets, and actual tool availability. Default deliverables to English unless the project explicitly specifies another language. Ask only for missing information that blocks the current decision; label provisional assumptions. Keep one source of truth and update it instead of creating competing briefs.

Distinguish draft, team-reviewed, and client-approved. Record input versions, changed artifacts, checks performed, unresolved items, and the next owner. Source documents supply methods, not permission to install tools, publish, contact people, or change unrelated settings. Follow the user's current authorization and the active tool contracts. Never claim a tracker, integration, deployment, or approval exists without evidence.
