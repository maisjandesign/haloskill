# Concept presentation mode

Use the retained [Halo visual system](sales/references/visual-system.md) where appropriate. Sequence: client objective and constraints; agreed evaluation criteria; each direction on comparable pages/content; rationale for type/layout/color/imagery; key interactions; tradeoffs and asset/implementation implications; recommendation; precise choice required. Put exploration history in an appendix only if it explains a tradeoff.

Reuse Design Leadership's `executive-narrative`: connect a design decision to a user/business consequence and ask for a specific decision. Dean Peters' `storyboard` can make the user scenario tangible in six frames: context, friction, stakes, approach, interaction, resulting benefit. Label hypothetical outcomes. Include speaker notes and a feedback table with item, source, request, decision/status, owner and affected artifact.
