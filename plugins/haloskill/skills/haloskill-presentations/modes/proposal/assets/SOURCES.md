# Asset provenance

Assets in this directory were derived from or bundled from the approved Halo Lab Branding Roadmap reference at https://halolab-design.webflow.io/#1 on 2026-09-01.

- `halo-logo.svg`: Halo Lab logo from the live reference.
- `icon-*.svg`: interface/contact icons from the live reference.
- `reference-*.webp|jpg`: visual reference images from the live reference; use only when appropriate to the proposal.
- `folder-tab-*.svg`: editable reconstructions of the reference deck's folder-tab geometry using the measured brand palette.

No font files are bundled. Use Suisse only when it is already installed and licensed; otherwise use the documented portable fallback.
