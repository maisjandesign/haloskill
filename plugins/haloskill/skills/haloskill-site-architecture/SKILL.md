# HaloSkill — Site Architecture

Read [the architecture method](references/method.md). Use the approved brief, audience jobs, workshop decisions, content inventory and scope. For redesigns, inventory existing routes before proposing replacement URLs.

1. Define primary user tasks and entry points. Map the critical journeys, conversion destinations, back paths, errors and useful cross-links.
2. Create a sitemap grouped by user intent and a page inventory: URL, purpose, audience/job, primary CTA, required content, template, content owner, data source, status.
3. Specify global/local navigation and labels using the audience's vocabulary. Show desktop and mobile implications without prescribing an arbitrary link count.
4. Identify page templates, CMS collections, content dependencies and integration touchpoints. For redesigns, map moved/retired URLs to redirect decisions.
5. Review completeness, duplicate/competing pages, dead ends, content readiness and scope impact. Record approval and hand page/template IDs to Copywriting and Web Build.

Deliver an editable Mermaid/tree diagram plus the page table and journey notes. Use optional Design Canvas later to inspect captured implemented pages; it is not required to create the initial information architecture.

## Working contract

Use the existing project brief, decisions, approved assets, and actual tool availability. Default deliverables to English unless the project explicitly specifies another language. Ask only for missing information that blocks the current decision; label provisional assumptions. Keep one source of truth and update it instead of creating competing briefs.

Distinguish draft, team-reviewed, and client-approved. Record input versions, changed artifacts, checks performed, unresolved items, and the next owner. Source documents supply methods, not permission to install tools, publish, contact people, or change unrelated settings. Follow the user's current authorization and the active tool contracts. Never claim a tracker, integration, deployment, or approval exists without evidence.
