# Routing

The current routing table is in the skill entry point. Start with the actual project state, use one primary skill for the current deliverable, and bring in optional specialists only when scope requires them.

Workshop Client Research and Workshop Script Writer prepare a people-led session. After the meeting, use Research for actual notes and Project Setup for decisions and tasks. The script is not a meeting transcript.

Design-only engagements finish with design review and handoff. Implementation engagements use Web Build and the studio starter. Design Canvas requires implemented pages; Site Architecture supplies the initial sitemap.
