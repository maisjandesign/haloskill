# Маршрутизация

| Этап / задача | Основной skill | Дополнительно по необходимости |
|---|---|---|
| 1. Запрос и запуск | haloskill-project-setup | haloskill-decisions, haloskill-proposal-deck |
| 2. Ресерч | haloskill-research | Для content workshop: haloskill-workshop-client-research |
| 3. Workshop | haloskill-workshop-client-research → haloskill-workshop-script-writer | Оба пользовательские, без переработки содержания |
| 4. Концепты маркетингового сайта | haloskill-concepts | haloskill-imagegen, haloskill-layout, haloskill-typography |
| 4. Продуктовый интерфейс | haloskill-interface-design | haloskill-ux-writing, haloskill-accessibility |
| 5. Презентация в Figma Slides | haloskill-sales-presentation | haloskill-decisions |
| 5. Презентация в PPTX/PDF | haloskill-presentations или haloskill-proposal-deck | haloskill-design-review |
| 6. Система и главная | haloskill-figma-library, haloskill-design-system-rules, haloskill-figma-to-code | haloskill-code-connect или haloskill-figma-component-mapping |
| 7. Остальные страницы | haloskill-figma-to-code / haloskill-interface-design / haloskill-concepts по исходным материалам | Утверждённые компоненты и правила проекта имеют приоритет |
| 7. Сайт именно на Sites | haloskill-site-build | haloskill-site-publish при публикации |
| 8. QA и передача | haloskill-design-qa, haloskill-handoff | haloskill-accessibility, haloskill-design-debt |

Это подборка инструкций, не автоматическая очередь. Не запускай следующий этап без соответствующей задачи. CMS, Storybook и внешние сервисы требуют конкретного репозитория, стека и инструментов; наличие названия в плане не означает работающую интеграцию.
